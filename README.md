# HX-Remo

This repository contains a small educational program for learning how AI training works.

## Run it

```bash
python3 train_to_be_ai.py
```

The program trains a tiny neural network to learn XOR. It is deliberately small and dependency-free so the training loop can be inspected directly.

## What it does and does not show

- Proven: repeated weight updates can reduce error on a small supervised dataset.
- Hypothesized: the same basic training pattern scales to more useful models when paired with more data, compute, and better architecture.
- Speculative: this toy model says much about general intelligence. It does not.
