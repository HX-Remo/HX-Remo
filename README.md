# Pocket Playground

A tiny touch-first web toy that runs in Safari on an iPhone. Tap or drag inside the play field to spawn colorful bouncing orbs, then use the controls to add a burst, calm the motion, or clear the screen.

## Run locally

From this repository, start any static web server:

```bash
python3 -m http.server 8080
```

Open `http://localhost:8080` on your computer, or open `http://<your-computer-ip>:8080` from an iPhone on the same Wi-Fi network.

## iPhone tips

- In Safari, use the share button and choose **Add to Home Screen** for an app-like launch icon.
- Keep the phone and computer on the same Wi-Fi network if you are testing from the development server.
